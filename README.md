## Задача

Даны две строки `s` и `t`. Нужно вернуть `True`, если из букв `s` можно составить `t`, использовав каждую букву ровно столько раз, сколько она встречается в `s`. В остальных случаях нужно вернуть `False`.

## Решение

В файле `valid_anagram.py` задача решена методом `isAnagram` класса `Solution`. Я сортирую символы обеих строк с помощью `sorted()` и сравниваю полученные списки. Если списки равны, метод возвращает `True`.

## Почему это работает

После сортировки одинаковые буквы стоят рядом. Если в обеих строках каждая буква встречается одинаковое число раз, отсортированные списки совпадут.

Если хотя бы одной буквы в одной из строк больше или меньше, списки будут отличаться. Например, в `aab` и `abb` встречаются одни и те же буквы, но в разном количестве. После сортировки списки остаются разными, поэтому метод возвращает `False`.

## Сложность

Пусть `N` — суммарная длина двух строк.

- Время в худшем случае — **O(N log N)**. Основную работу занимает сортировка, а сравнение списков занимает не более O(N).
- Дополнительная память — **O(N)**. `sorted()` создаёт два списка символов.

## Примеры

| `s` | `t` | Результат |
|---|---|---|
| `"anagram"` | `"nagaram"` | `True` |
| `"cat"` | `"rat"` | `False` |
| `"aab"` | `"abb"` | `False` |
| `"ab"` | `"abc"` | `False` |

Из папки проекта выполните:

```bash
python3 -c 'from valid_anagram import Solution; print(Solution().isAnagram("anagram", "nagaram"))'
```

Команда выводит `True`.
